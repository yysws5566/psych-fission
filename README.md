# psych-fission · 心理模型裂变工坊

> 同一个产品，锚定效应写出来是价格锚，损失厌恶写出来是怕错过，身份认同写出来是「把关人」——模型不同，写法根本不同。每个版本是一个可验证的心理机制。

## 案例标题（SkillHub用）

心理模型裂变工坊——36个营销心理学模型：5 Whys挖根因，每个机制各写一版，附文案体检模式

## 简介

心理模型裂变工坊・营销心理学驱动的多版本交付机制。36个营销心理学模型卡（认知偏差8/西奥迪尼说服6/行为经济学6/好奇注意5/社会身份6/决策结构5），六阶段流水线——任务登记（5 Whys挖受众购买根因到身份/情绪层，先挖根因再选模型）→模型竞拍（心理机制匹配度<60出局）→裂变写作（每个模型一写一版完整产物，机制即写法，正文带机制落点标注）→加权投票（最佳钩子/最佳转化/最佳风险预警，理由必须引用模型机制）→主编综合（模型组合公式≤3机制+装填版+条件式投放+A/B测试清单），另含诊断模式（对已有文案逐段做心理机制体检，标注已用/漏用机制）。

## 适合人群

投放优化师、电商文案、私域操盘手、品牌营销人——想知道「为什么这版文案有效」而不只是「哪版好看」的人；手里有现成文案想找出问题、不想推翻重写的人。

## 能解决的问题

- 写文案全凭手感，说不清哪句在起作用，A/B测赢了也不知道为什么赢
- 多版文案共用同一个心理机制只换皮，测试跑了个寂寞
- 已有文案想优化，但不知道漏了什么机制、哪句话在拖后腿
- 机制乱堆：稀缺+权威+从众+损失厌恶全上，每个都不狠

## 使用步骤

1. 说清任务：产品、受众画像、成功指标（转化/完播/回复率）
2. skill先跑5 Whys挖购买根因（「他不是在买X，他是在买___」），再让36个模型竞拍，TOP席位每个模型各写一版带机制落点的完整文案
3. 交叉投票+主编综合出模型组合公式（≤3机制）与装填版；按A/B清单测试——CTR差异可直接归因到机制
4. 给现成文案时自动切诊断模式：逐段扫机制、给最小改动版改写稿

## 使用Prompt（复制即用，{{}}处替换或设为占位词）

```
请用心理模型裂变工坊为我裂变文案：

任务：为{{产品/服务}}写{{产物类型：种草文案/广告素材/直播话术}}
受众：{{受众画像：年龄/身份/核心顾虑}}
成功指标：{{如：3秒完播、CTR、转化成本}}

先对「受众为什么会买」跑5 Whys挖到身份/情绪层根因，再让36个心理模型卡竞拍（根因匹配≥60入围），TOP席位每个模型各写一版完整文案并标注机制落点（锚定/损失厌恶/身份认同/社会认同等）。

加权三维投票（钩子/转化/风险预警，理由必须引用机制），主编综合出模型组合公式（≤3机制）+装填版+条件式投放+A/B测试清单。广告类过广告法禁词扫描。交付md产物集+HTML竞拍报告。
```

## 文案体检Prompt（诊断模式，复制即用）

```
请用心理模型裂变工坊的诊断模式，给我这份文案做心理机制体检：

文案原文：{{粘贴文案全文}}
受众：{{目标受众画像}}
目标：{{希望提升什么指标}}

逐段标注实际触发的心理模型，给出机制覆盖图（已用/漏用清单）、机制-受众错配审计，以及只动机制触发点不动风格的最小改动版改写稿。
```
